# Getting help

- Setup trouble or "how do I...": ask in [Discussions](https://github.com/uniz-rguktong/uniz-master/discussions) (Q&A category). Someone usually answers within a day or two.
- Found a bug: open an issue with the bug form in [uniz-master](https://github.com/uniz-rguktong/uniz-master/issues/new/choose).
- Security issue: follow [SECURITY.md](SECURITY.md), not a public issue.
- Problem with your UniZ account (login, wrong marks, outpass stuck): that's not a code issue, contact your campus admin or the UniZ team at uniz@rguktong.ac.in.

Please don't DM maintainers for setup help. Asking in public means the next person finds the answer.
